# BIND 계정 삭제 안내

BIND 앱 계정과 관련 데이터를 삭제하는 방법을 안내합니다. 계정을 삭제하면 되돌릴 수 없습니다.

## 1. 앱에서 직접 삭제하기 (권장)

1. BIND 앱을 열고 로그인합니다.
2. 하단 탭의 **마이페이지**로 이동합니다.
3. **계정**을 누릅니다.
4. **탈퇴하기**를 누르고, 확인 창에서 **탈퇴**를 누릅니다.
5. Apple로 가입한 경우 Apple 확인 창이 한 번 더 나타납니다. 확인하면 Apple 로그인 연결도 함께 해지됩니다.

탈퇴가 끝나면 로그인 화면으로 돌아갑니다.

## 2. 앱을 쓸 수 없을 때 이메일로 요청하기

앱을 이미 지웠거나 로그인할 수 없다면 아래 이메일로 삭제를 요청해 주세요.

- 받는 사람: <futureworkers.global@gmail.com>
- 제목: BIND 계정 삭제 요청
- 내용: 가입에 사용한 Google 또는 Apple 계정의 이메일 주소

본인 확인을 위해 **가입한 계정의 이메일 주소에서 보내 주세요.** Apple 로그인에서 이메일 가리기를 사용했다면, 가입 시 Apple이 만든 중계 이메일 주소(@privaterelay.appleid.com)를 함께 알려 주세요. 요청을 받은 날부터 10일 안에 삭제하고 결과를 이메일로 알려 드립니다.

## 3. 삭제되는 데이터와 보관 기간

| 데이터 | 처리 |
| --- | --- |
| 계정(로그인 정보, 이메일 주소, 이름), 프로필(닉네임, 하는 일, 동의 기록) | 탈퇴 즉시 삭제 |
| 체크인 기록(장소, 주제 한 줄, 키워드) | 탈퇴 즉시 삭제 |
| 보내고 받은 대화 요청 | 탈퇴 즉시 삭제 |
| 차단 목록, 푸시 알림 토큰 | 탈퇴 즉시 삭제 |
| 1:1 채팅방, 메시지, 대화 평가 | 대화방이 열린 때부터 7일 뒤 자동 삭제 |
| 신고 기록 | 신고 접수일부터 1년 보관 후 삭제(분쟁 대응과 반복적인 부정 이용 방지) |
| 앱 이용 통계(Google Analytics) | 이용자를 직접 알아볼 수 없는 형태로, 보관 설정에 따라 최대 14개월 보관 후 삭제 |

탈퇴 후 대화 상대의 화면에는 "떠난 사용자"라는 표시만 남습니다. 이 표시에는 닉네임 등 이용자를 알아볼 수 있는 정보가 없습니다.

자세한 내용은 [개인정보처리방침](../privacy/)을 참고해 주세요.
